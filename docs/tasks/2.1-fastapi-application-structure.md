# Task 2.1 — FastAPI application structure

## Objective

An ASGI application that starts, with the assembly points every later task plugs
into: an app factory, a lifespan, and one place routers are mounted.

## Context

`apps/api` has dependencies, settings (0.5), tooling and a container image, but no
application — `scripts/dev-api.sh` reports exactly that. Task 0.5 fixed the
settings contract; this consumes it.

## Implementation steps

1. `api/app.py` — `create_app(settings)` factory plus a module-level `app` for
   uvicorn. A factory so tests build an app with their own settings.
2. Lifespan for startup and shutdown, with nothing in it yet beyond a log line.
3. A settings dependency, so handlers receive configuration rather than importing
   a singleton.
4. One trivial route to prove the wiring; health endpoints are 2.6.
5. Make `scripts/dev-api.sh` actually run it.
6. Tests: the app builds, the route answers, the factory accepts injected settings.

**Excluded:** health checks (2.6), logging (2.7), error handling (2.8), versioning
and the `/api/v1` prefix (2.9), OpenAPI metadata (2.10), database (2.3).

## Acceptance criteria

- `scripts/dev-api.sh` starts a server that answers.
- `create_app` accepts settings, so a test never touches the real environment.
- Tests cover: app builds, route responds, injected settings are used.
- `scripts/check.sh` passes.

## Tests

pytest with `httpx.ASGITransport` — no network, no port.

### Deviations
- **`/` is an identity route, not a health check.** Conflating them means a load
  balancer keeps routing to a process that cannot reach its database. 2.6 adds the
  real ones.
- **`asyncio_mode = "auto"`** in pytest config: every async test here is a
  coroutine, and marking each one adds noise without information.
- **Tests share a `BuildSettings` alias from `conftest`.** The first version typed
  the fixture as `object` with `type: ignore` at each call — that is the kind of
  cast the frontend rules forbid, and it applies here too.

### Known limitations
- Nothing in the lifespan yet; the engine and Redis pool arrive in 2.3.
- No `/api/v1` prefix (2.9), no error envelope (2.8), no logging (2.7).
