# Task 1.3 — Design tokens

## Objective

Complete the token set with the dimensions task 1.2 needed and 0.8 did not model:
stacking order, motion, and the layout metrics of the shell — so none of them
survive as magic numbers.

## Context

**This task overlaps task 0.8.** 0.8 delivered colour, type, spacing, radii and
elevation, measured against WCAG AA. Rather than redo that, this task closes the
gaps 1.2 exposed and makes the token system enforceable.

## Implementation steps

1. Z-index scale as tokens, with the layers named (drawer, backdrop, header,
   popover, toast). Replace any raw `z-*` introduced by 1.2.
2. Motion tokens: two durations and two easings, honoured by
   `prefers-reduced-motion`.
3. Layout metrics: header height, sidebar width, content max width — referenced by
   the shell rather than repeated.
4. Extend `/design` with the new groups.
5. A check that fails on a raw hex colour outside `globals.css`, wired into
   `scripts/check.sh`, so token discipline is enforced rather than reviewed.

## Acceptance criteria

- The shell contains no raw z-index, duration or dimension value.
- The new tokens appear on `/design`.
- The raw-hex check fails on a deliberately introduced literal, then passes.
- Contrast and `scripts/check.sh` still pass.

## Tests

Verification is the enforcement check failing on a planted violation, and grepping
the shell for literals.

### Deviations
- **This task overlapped 0.8 substantially.** 0.8 already delivered colour, type,
  spacing, radii and elevation with measured contrast. Rather than redo it, this
  task closed the gaps 1.2 exposed. Flagged to the user before starting.
- **Tailwind 4 has no `z` or `duration` theme namespace** — only animate, aspect,
  blur, breakpoint, color, container, default, drop, ease, font, inset, leading,
  max, perspective, radius, shadow, spacing, text, tracking. `@theme` entries for
  those two generated no utilities at all. Read from the installed `theme.css`,
  then declared them with `@utility`.
- **Enforcement lives in `check-contrast.mjs`**, which already owns colour
  discipline, rather than a new script. Two files are exempt with the reason
  recorded next to each.
- **`prefers-reduced-motion` also zeroes the tokens**, not just the computed
  properties, so code reading `--duration-*` directly is covered.

### Known limitations
- Layers above `z-drawer` (`popover`, `toast`) have no consumer yet; they exist so
  the order is decided once rather than negotiated per component.
- The raw-hex check covers `apps/web/src`; `rgb()`/`hsl()` literals are not caught.
