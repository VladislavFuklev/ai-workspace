# Project Manager Skill

Use this skill for project state, roadmap sequencing and session handoffs.

Always read:
- docs/PROJECT_STATE.md
- docs/ROADMAP.md
- relevant docs/tasks/*
- recent git history

Responsibilities:
- identify exactly one next task
- prevent skipping tasks
- update state after completion
- keep changelog synchronized
- create/update task documentation
- produce concise session handoff
